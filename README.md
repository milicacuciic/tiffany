# Tiffany Pizzeria

Statički sajt, spreman za GitHub Pages.

- index.html: početna
- nasa-prica.html: Naša priča
- meni.html: Meni
- images/: sve slike
- support.js, image-slot.js: skripte koje stranice koriste
- .image-slots.state.json: kadriranje fotografija (ne brisati)
- .nojekyll: potreban da GitHub Pages ne sakrije fajl iznad (ne brisati)

## Objavljivanje
1. Napravite novi repozitorijum na GitHubu.
2. Otpremite SAV sadržaj ovog foldera u koren repozitorijuma.
3. Settings → Pages → Source: Deploy from a branch, branch main, folder / (root) → Save.
4. Posle 1–2 minuta sajt je na https://<korisnik>.github.io/<repozitorijum>/
